# IF PARTNERS HUKUK — ifhukuk.com

Sitenin kaynakları `src/` klasöründedir; yayınlanan HTML dosyaları `python3 build.py` ile deponun köküne üretilir
ve GitHub Pages bunları doğrudan yayınlar.

- Site bilgileri (telefon, adres, LinkedIn, logo): `src/site.yml`
- Çalışma alanları: `src/alanlar/*.md`
- Blog yazıları: `src/blog/*.md` (başında `title`, `date`, `category`, `description`)
- Şablonlar: `src/templates/`, stiller: `assets/site.css`
